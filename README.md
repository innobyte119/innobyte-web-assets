# innobyte-web-assets

File compilati serviti con jsDelivr al sito innobyte.it. Solo file pronti all'uso: il codice sorgente sta altrove.

- `pagina-ai/ai-page.js`, `pagina-ai/ai-page.css`: animazioni e stili della pagina «Intelligenza Artificiale».

Indirizzi sempre legati a un tag, per esempio:
`https://cdn.jsdelivr.net/gh/innobyte119/innobyte-web-assets@v1.0.0/pagina-ai/ai-page.js`
